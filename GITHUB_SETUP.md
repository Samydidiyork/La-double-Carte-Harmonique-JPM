## Comment ajouter les topics sur GitHub

1. Ouvrez votre dépôt sur github.com
2. Cliquez sur l'icône ⚙️ à côté de "About" (en haut à droite de la page)
3. Dans le champ "Topics", tapez chaque mot-clé et appuyez sur Entrée
4. Cliquez sur "Save changes"
